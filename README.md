# 獎懲紀錄產生器

跨 iPhone Safari、macOS、Windows 的純前端 Excel 工具。

網站：https://saissa444.github.io/reward-discipline-generator/

## 使用

1. 匯入學生名冊及獎懲範本。兩個檔案的選取順序不限。
2. 輸入女生隊號、建制隊號或姓名，可混用換行、空格、逗號、頓號分隔。女生隊號可省略前導零，也支援 `002-010` 範圍。
3. 依序選條、款、目。沒有「目」的款會自動略過，並帶入範本原始事由及固定額度。事由帶入後可直接自行編輯；更換條款目時會重新帶入對應範本事由。
4. 額度依範本各「條」的設定自動帶入，無法手動修改。加重減輕事由及加重減輕額度仍可選填。
5. 點「批次新增至預覽」，本批學生會接續加入既有紀錄。接著可以更換學生、獎懲依據或事由，再次新增下一批；原有紀錄與編輯內容都會保留。
6. 可點每列「編輯」修改單筆、「刪除」移除該筆，或核取多筆再點「編輯已選取」。直接點「匯出 Excel」下載目前全部預覽紀錄。iPhone Safari 下載後可到「檔案」App 開啟。

預覽編輯支援「獎懲依據（條款目）」、「獎懲事由」、「加重減輕事由與額度」三組欄位。額度僅顯示範本固定值，變更獎懲依據會同步更新為新條文的固定額度。事由可單筆修改或核取多筆後一次套用自訂文字，也可只改事由並保留各筆原條款目。修改加重減輕選項會保留自訂事由；更換條款目時會重新帶入對應範本事由，之後可再編輯。批次編輯僅套用勾選的欄位，其餘保留每筆原值；加重減輕內容可選「無」清除。學生姓名及學號依名冊保留。取消或驗證失敗不會改動原紀錄；成功儲存後會同步更新下載檔。

每列「刪除」會立即移除該筆並同步更新下載檔，其他列的勾選狀態會保留。「清空紀錄」會移除全部預覽與下載內容，保留匯入的名冊、範本及上方輸入。「清除輸入」僅重設上方學生與共同獎懲表單，保留所有既有紀錄。刪除最後一筆或清空紀錄後，匯出按鈕會停用；可再次批次新增。

同批及跨批次重複學生均保留，依輸入順序各新增一筆；用女生隊號、建制隊號、姓名輸入同一人也一樣。預覽下方會以紅字依學籍號碼統計，例如「共 3 筆，重複 2 次」。每筆可獨立編輯或刪除，紅字次數隨刪除或清空更新，Excel 會保留全部紀錄。查無或無法唯一確認的學生會以紅字提示並略過，其餘已辨識的學生仍可新增及匯出；預覽會顯示上次新增略過筆數。同名學生可改用女生隊號或建制隊號重新輸入。

更改上方學生、獎懲選項或清除輸入只影響下一批，現有紀錄及下載檔不變。新增失敗也會保留既有紀錄與下載。重新匯入名冊或範本會重設預覽，重新整理頁面則會清除所有本頁資料。

匯入內容僅存在當前頁面的記憶體中，重新整理後需要重選檔案。若 iCloud 檔案無法讀取，先將檔案下載至本機再選取。

## 資料與隱私

- 優先讀取 `姓名查詢`，欄位為姓名、建制隊號、女生隊號、學籍號碼。十位學籍號碼用於輸出，女生隊號會補至三位。
- 從 `獎懲項目` 讀取條款目、原始事由、各條固定額度、加重減輕額度選單及加重減輕事由。新增與編輯均由解析邏輯依條文決定固定額度；若範本缺少設定則顯示錯誤並保留原有紀錄。
- 匯出採用所選範本的原始工作表名稱、欄位順序及九個欄名，包括括號與「若無可不選擇」文字。輸出為已確認的資料值，不帶入範本空白列中的公式提示。
- Excel 經 `FileReader.readAsArrayBuffer` 在瀏覽器處理，不依賴 `Blob.arrayBuffer()`，也不會上傳名冊。
- SheetJS CE 0.20.3 內附於 `vendor/`，執行時無須連線第三方 CDN。原始來源：<https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js>；授權見 `vendor/SheetJS-LICENSE.txt`。
- **禁止提交真實學生名冊、姓名、學籍號碼、匯出結果及含個資截圖。** `.gitignore` 排除 Excel 等測試資料。測試檔只能放在儲存庫外。

```sh

```

完整瀏覽器測試（安裝開發相依套件與 Playwright 瀏覽器後）：

```sh
npm install
npx playwright install --with-deps webkit chromium
ROSTER_PATH=/private/roster.xlsx TEMPLATE_PATH=/private/template.xlsx npm run test:browser
TEST_BROWSER=chromium ROSTER_PATH=/private/roster.xlsx TEMPLATE_PATH=/private/template.xlsx npm run test:browser
```

WebKit 的 iPhone 模擬驗證不等於在實體 iPhone 上操作 Safari／iCloud 檔案選取器。
